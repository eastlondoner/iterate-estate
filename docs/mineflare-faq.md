# Mineflare FAQs

Q: What is Mineflare
A: Mineflare is a Minecraft server hosting service that runs on Cloudflare

Q: How much does Mineflare cost
A: it costs 50 cents per hour that your Minecraft server is running.

Q: What if I forget to turn off my Mineflare server
A: Minecraft servers automatically shut down after 20 mins of inactivity
